# Settings

COSMO Smart Automate provides a set of settings and admin pages to control the rule engines. These are the current settings and administration areas:

Related documentation:
- [Parent Rules](./PARENT_RULES.md)
- [Preset rules](./PRESETS.md)

## Administration Pages

Access COSMO Smart Automate configuration through the project settings:

| Page                  | Purpose                                                               |
| --------------------- | --------------------------------------------------------------------- |
| Parent Rules          | Create, edit, and manage **Parent Rules**                             |
| Work Item Calculation Rules | Create, edit, and manage **Work Item Calculation Rules** for field calculations |
| Import / Export       | Export selected rule sets or import a supported rule bundle       |
| Sibling Rules Admin   | Create, edit, and manage **Sibling Rules** for task coordination      |

## Settings

> Only use work item types defined in this projects process

This controls what work item types are shown in the dropdowns while configuring rules. It only controls the UI and not any functionality.

| State | Description                                                                                      |
| :---: | ------------------------------------------------------------------------------------------------ |
|  On   | When this setting is on, only the work item types defined in the current process are shown. |
|  Off  | When this setting is off, all work item types are shown.                                     |
